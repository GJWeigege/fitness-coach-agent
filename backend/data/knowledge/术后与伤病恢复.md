# 术后与伤病恢复

## 通用原则
- **外科医生/康复师方案优先**于网络通用计划。
- 无痛活动度 → 稳定 → 力量 → 爆发力 → 专项，顺序加载。
- **渐进回归**：疼痛消失且功能改善时，每周负荷约增 10%。

## 常见术后时间线（高度个体化，非处方）
- **前交叉韧带重建**：重返运动常 9–12 个月以上；跳跃测试需左右对称达标。
- **肩袖修复**：过头负重常 4–6 月；勿过早大重量推举。
- **髋/膝置换**：系统康复常 12 周以上；低冲击起步。
- **脊柱手术**：屈伸与负重限制依主刀医嘱。

## 恢复期营养
- **充足蛋白** 1.6–2.2 克/公斤支持组织修复；偏瘦可略盈余，勿极端节食。
- **微量营养素**：维生素 C、锌、足够热量；练前 30–60 分钟胶原+维生素 C（肌腱研究中有一定证据）。
- 限酒（妨碍愈合）；充分补水。

## 训练替代
- 下肢手术：经许可后早期可做上肢坐姿训练。
- 上肢受限：腿举、固定单车、稳定类核心。
- **血流限制训练**：须在康复师监督下进行，负荷受限时用低重量维持肌量。

## 心理
- 身份暂时转变；庆祝活动度等小里程碑。
- 勿与社交媒体上的「伤前进度」盲目比较。

## 红旗
- 疼痛加重、新麻木、手术部位发热、下肢术后小腿肿胀 → 联系医生。

## 本助手边界
- 不提供具体术后周计划；请遵循医疗团队方案，本内容仅供一般恢复教育。
