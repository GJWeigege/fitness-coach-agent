# 素食与植物蛋白

## 蛋白目标
- 素食/纯素训练者蛋白建议 **1.6–2.2 克/公斤/天**，与杂食者相同；注意氨基酸完整性与亮氨酸摄入。

## 优质植物蛋白来源
- **大豆**：豆腐、天贝、毛豆；完全蛋白，亮氨酸含量较好。
- **豆类+谷物**：豆+米、鹰嘴豆+全麦，互补氨基酸。
- **面筋（小麦蛋白）**：高蛋白，但麸质敏感者避免。
- **蛋白粉**：大豆、豌豆、大米、大麻或混合植物蛋白；训练后便利补充。

## 关键微量营养素
- **维生素 B12**：纯素必须补充或选强化食品。
- **铁**：植物铁吸收低，与维生素 C 同食；定期验血。
- **锌、钙、欧米伽-3**：藻类油补剂、强化植物奶、坚果种子。
- **维生素 D**：缺乏时补充，与饮食模式无关。

## 训练日安排
- 每餐含 20–30 克蛋白；练后豌豆/大豆蛋白粉 + 水果碳水。
- 肌酸一水合物 3–5 克/天对素食者**尤其**有益（日常饮食肌酸摄入低）。

## 常见挑战
- **饱腹感高、热量低**：增肌期用坚果、牛油果、橄榄油提高密度。
- **外食**：提前查菜单，选豆制品、沙拉加鹰嘴豆、米饭碗。
- **「蛋白不够」误区**：计划得当完全可满足；记录 3 天宏量确认。

## 纯素增肌
- 热量盈余 + 渐进式超负荷原则不变；监测 B12、铁、维生素 D。
- 本助手提供一般营养教育，特殊医疗状况请注册营养师个体化方案。
